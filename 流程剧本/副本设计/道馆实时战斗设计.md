# 道馆实时战斗设计

## 战斗技能原则

RTC 的战斗招式需要同时满足宝可梦当前形态的 Cobblemon 合法招式表和 RTC `MoveRegistry` 的运行时招式表。状态招式、零威力招式、反制/保护类招式、自爆和一击必杀不进入道馆实时战斗配招。队伍生成时会从合法候选中优先为每只宝可梦安排不同形态的攻击，尽量覆盖范围落点、区域冲击、突进、远程弹道、光束和近身招式；`chargeTicks` 大于零的招式优先，以保留玩家观察并闪避的时间。候选不足时才按评分补齐，不会强塞 RTC 不支持的招式。

合法伤害招式不足四个时允许空槽，不用撞击凑数。内置阵容必须至少有一招合法的实时伤害招式；武藏使用饭匙蛇，替换只有反制和状态招式的果然翁。Mega、神兽和剧情对局优先保留已配置、合法且可施放的招式，其余空位优先补本系攻击和不同攻击形态。

RTC `MoveStyle.Shape` 的设计用途：

| 形态 | 战场表现与玩家应对 |
| --- | --- |
| `RAIN` / `STRIKE` | 落点或区域攻击；观察地面/预警并离开范围。 |
| `SHOCKWAVE` | 近身范围压制；拉开距离或及时闪避。`EXPLODE` 不在当前 RTC NPC AI 的可施放形态里。 |
| `DASH` | 突进接近；横向闪避比后退更有效。 |
| `PROJECTILE` / `BOLT` / `BEAM` / `STREAM` | 远程直线或弹道攻击；利用移动、格挡或视线遮挡处理。 |
| `MELEE` | 近身打击；保持距离并在前摇期间闪开。 |

具体招式的形态、威力、命中率和前摇由当前依赖中的 RTC 数据驱动；每次部署会打印 `[ArenaMoves]` 日志，改 RTC 版本或资源包后应重新核对日志，不能仅凭宝可梦原作招式名推断其游戏内效果。

## 道馆馆主队伍

馆主副本启用 hard 模式时，使用下列强化队伍。对局部署会从物种当前形态的合法招式中替换成 RTC 可执行技能；物种和等级在这里列出，最终技能以启动日志 `[ArenaMoves]` 为准。

| 道馆 | hard 队伍 |
| --- | --- |
| 岩石 | Archen 17、Nosepass 17、Minior 17、Lileep 17 |
| 草 | Hisuian Electrode 25、Sunflora 24、Ludicolo 25、Victreebel 25、Lilligant 26 |
| 幽灵 | Gengar 30、Spiritomb 28、Mismagius 30、Drifblim 28、Mimikyu 29 |
| 冰 | Ninetales 38、Cetitan 39、Sandslash 38、Glaceon 38、Lapras 38、Spheal 36 |
| 地面 | Hippowdon 45、Nidoking 45、Garchomp 48、Excadrill 48、Krookodile 46、Golem 46 |
| 火 | Ninetales 52、Darmanitan 52、Charizard 54、Gouging Fire 54、Arcanine 52、Ceruledge 52 |
| 恶 | Meowscarada 60、Spiritomb 60、Roaring Moon 62、Gyarados 65、Umbreon 60、Obstagoon 62 |
| 电 | Magnezone 66、Rotom 66、Luxray 66、Eelektross 66、Raging Bolt 68、Manectric 68 |

普通模式沿用 `GymLeaderTeams` 的原队伍；hard 模式由 `hardGymBattles` 配置控制，入口大厅模板和正式副本定义必须同为 `_hard`。多人挑战时每增加一名玩家，馆主队伍最大生命按人数倍增。

## 对手反应

道馆副本内，RTC 检测到玩家已提交蓄力/重击窗口后，馆主宝可梦才会尝试反应。反应带 3-5 tick 观察延迟、46-64 tick 冷却和概率失败；成功时按场地碰撞选择侧闪或短时格挡。普通馆主的触发率为 30%，hard 馆主为 55%，因此不会连续或必定格挡。闪避方向必须通过碰撞检测。该逻辑不作用于野外、PvP、教学和电影模式。

## 验收

改 RTC 版本、物种学招表或固定阵容后，用临时世界运行服务端检查：

```sh
./gradlew --offline runServer -PrumbleAuditArenaRosters=true -PrumbleServerWorld=rumble-arena-audit
```

在日志中查找 `[ArenaAudit]`。它检查道馆、剧情、Mega、神兽和电影阵容的构造、合法配招、每个成员至少一个伤害招式，以及指定伤害招式是否保留。路人训练师和模拟道馆的阵容由前置模组在游玩时提供，走同一个配招入口；确实无合法伤害招式时仍允许 RTC 普攻，避免外部阵容导致开战失败。阵容检查不替代游戏内开战验收。

1. 通过馆主对话打开大厅，确认标题/定义为 hard 模板（配置关闭时为普通模板）。
2. 启动后检查每只宝可梦的 `[ArenaMoves]` 日志；任何招式必须同时在 Cobblemon 合法表和 RTC `MoveRegistry` 中。
3. 观察蓄力攻击，确认有可反应前摇、反应会失败且有冷却，且只影响道馆实例中的馆主。
