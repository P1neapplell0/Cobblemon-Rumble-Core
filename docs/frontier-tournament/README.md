# 对战开拓区：多人赛制

直接打开 `index.html`。页面下方的模拟按钮用于代替其他客户端；头像和宝可梦头图沿用 `../frontier-console/assets/`。这是交互预览，不会调用 Minecraft、扣款或发送真实聊天消息。

## 体验路径

- 大厅可筛选全部、1v1 或多人。创建默认选中 1v1；切到多人后，准备房只显示玩家席位和准备状态。
- 多人房中选「补到 5 人」和「其他玩家准备」，自己点准备，再开始赛程。首轮轮空；Esc 挂到左上角，R 恢复。用「结算其它对局」推动下一轮，从配队界面可以选择宝可梦并和对手准备。也可从大厅模拟收到一条原版聊天邀请。
- 快照入口：`?demo=create`、`?demo=ready`、`?demo=bracket`、`?demo=bye`、`?demo=lineup`、`?demo=awards`、`?demo=awards3`。

## 游戏内规则

- 建房时通过下拉框选择赛制和宝可梦来源。默认 1v1 且可用所有宝可梦。多人房的人数上限可留空，填写时至少为 4 人，实际满 3 人且全员准备即可开赛。正式版由服务端抽签；预览固定抽签。轮空、已打完和已淘汰的玩家留在带头像的赛程图，也可 Esc 回世界、R 恢复。每轮对局全部结束后再推进。赛程图顶部固定显示自己的本轮对手，支持滚轮、上下翻页和左右切换轮次。
- 自带队伍房使用加入房间时队伍中最靠前的三只宝可梦。不足三只时按实际数量参赛。副本使用保留等级、招式和携带物的满血副本。
- 3 人赛：一人轮空进决赛，首场败者列第三，奖金按 60%／25%／15%。4 人及以上：半决赛败者打季军赛，前四名按 50%／25%／15%／10%。比例按实际参赛人数而非房间上限决定，整数余数归冠军，只在整个赛事结束时结算。
- 每个房间对同一玩家只能邀请一次，可以连续邀请不同玩家。发送后列表内该玩家的按钮变为不可按的「已邀请」，不弹确认窗。同一发送者跨房间对同一玩家有 60 秒冷却。发送和接受都要校验房间状态、余位及玩家是否在副本或其他房间；签表锁定后停止邀请。
- 游戏内复用现有 1v1 配队页。每轮先亮签 5 秒，再给 180 秒配队；两人准备后自动进入独立副本。副本创建失败时清除本场准备状态供双方重试，不重复收款；准备时限到了，只有一人准备则该玩家晋级，两人都未准备则该对局无人晋级。对局中退出或掉线按弃权处理，配队时掉线可在本轮时限内重连。
- 报名时托管入场费，赛事结算后统一发放，离线玩家上线领取。开赛前解散、比赛没有冠军、正常停服或重启后恢复到存盘中的未结算托管记录时退款。
- `./gradlew --offline frontierBracketCheck` 验证 3–128 人的签表及奖金结算；游戏截图用于验证界面渲染，不能替代多客户端赛事联调。
