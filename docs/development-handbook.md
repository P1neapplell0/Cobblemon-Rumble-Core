# 剧情与玩法开发手册

继续接手时，先核对 `流程剧本/`、本章节现有实现、当前依赖源码和旧核心同类功能。旧核心用作行为参考；实时战斗、实例生命周期和玩家数据按本项目实现。未发布阶段不加旧存档迁移。

## 固定 NPC、演出与副本

- `FixedStoryActors` 是试炼殿堂固定角色的入口。博士、馆主、小弟、小瑶、武藏、小次郎和场景喵喵在首次建档时统一放置并写入区块实体存档。道馆站位和配队入口见 `GymCatalog`。维度、角色 ID、实体类型和稳定 UUID 用于判重，不能用名字或物种清理实体。
- 不在靠近、登录、读档或找不到实体时补刷。修复命令为 `/rumble refreshnpc`（权限等级 2）：等待预设区块的实体数据加载，保留已有角色，仅补齐缺失角色，并报告失败，不改任务或副本。新加角色后可在开发存档用此命令补齐。
- 对话实体供全服共享；任务阶段或演出节点只改当前玩家的追踪可见性。出入场烟雾、音效、运镜、Quark 表情按观看者隔离。隐藏角色不得出现交互提示、参与战斗或被捕捉；服务端校验身份、距离、视线和阶段。
- 只有负责出战、收回、换将或胜负表演的角色才在副本内临时创建。战后回到原地图上的同一 NPC，通过 ArcQuest 对话结算；剧情败退可重新挑战，不推进胜利目标。馆主的首通与重战分开，排行榜只记录确认结算的挑战。布局、外部训练师结算与场地分配见 [序章部署说明](prologue.md)、[实时玩法](realtime-gameplay.md) 和 [主题竞技场](battle-arenas.md)。

## 任务、奖励与引导

- 复用 [ArcQuest 剧情规范](arcquest-story.md)：主线金、支线蓝，路标同步主题色；先发主线再发支线以自动追踪支线。接任务用紫色提示窗，不加 splash。MineChat 只作插曲，不要求读完。
- 连续剧情（如序章出发、模拟战、回访）用同一个任务的不同阶段。路标指向真实互动对象；多人对白按节点切换说话人与运镜。统一用 `RewardNotice` 生成括号奖励描述及注册物品的翻译名，奖励和任务推进独立防重。
- 指南使用 ArcQuest，在对应解锁节点发放。截图切英文、裁掉无关窗口和 HUD，记录必要的操作步骤。见 [指南检查项](arcquest-guides.md#新指南检查项)。
- 教学允许自由移动，只在关键动作节点限制输入；使用可重绑按键的翻译、成功反馈音、适当的提示光圈和短暂淡入淡出。减速仅作用于私人教学维度。对话提示只在玩家近距离瞄准 NPC 时出现，摆在 NPC 身侧。只有客户端实际画出提示才发送按键请求，服务端复核朝向与遮挡。固定 NPC 保留重力和方块碰撞。

## 界面、联调与部署

- 界面采用 [Ore UI](ore-ui.md)；外观代码与业务逻辑分包，保留原生交易和战斗换将行为。博士商品和定价见 [交易表](professor-shop.md)。
- 道馆地图和实例模板放 `config`，随 `modpack_override/config` 交付；仅收录改过的配置，不用 `run/` 或存档里的 `data/` 当发布来源。每次修改覆盖包后运行 `./gradlew syncRunOverrides`，同步三个本地测试运行目录。
- 用隔离存档检查奖励防重、战败或断线重试。修改固定角色时再验证双玩家不同阶段、站定时显隐切换、卸载和重启后 UUID 不变、删除后不自动补刷，以及管理员修复和副本清理互不影响。

### 单人剧情调试

`config/cobblemon_rumble_core-common.toml` 的 `[developerMode]` 下启用 `skipNpcBattles = true`。进入 NPC 副本并触发开战后，按胜利流程结算，可继续验证战后对白、奖励和任务。此开关默认关闭，仅在未开放局域网的单人世界生效。

## 第四馆和每日委托

- 冰馆赠礼、博士短信、狩猎地带简报是第四馆主线的连续阶段。短信可跳过，博士简报结束后依次发放第五馆主线、狩猎地带和流浪商人支线。博士后期的默认对话需随章节继续更新。
- 模拟器复用 CobbleSafari 的确认、收费、计时、补给和返回。整合包在 `modpack_override/config/cobblesafari/safari_config.json` 配置 5,000 宝可币入场费，按 CobbleSafari 自身的每日周期计费；当日已付且还有时长可直接再进。保留原生缓降，但将入场落点调至地表上方四格，避免长时间缓降被服务器判为飞行。流浪商人是固定 NPC，解锁前根据玩家追踪状态显隐，交茶后常驻。黑市货架每 24,000 游戏刻刷新，已打开的旧货架不能用于下单。
- 每日委托和成长任务在序章结束时开放；每日委托沿用旧核心的冒险分类，分组排在成长任务之后，主题色为 `#5AD7FF`。以主世界游戏日换单，旧委托作废，每个玩家当天只能接受抽到的委托。使用事件统计，任务完成后立即发奖。个人维度的委托仅在个人维度任务完成后加入抽选。
- 试炼殿堂在开服前比较 `config` 预设的逐区 SHA-256。只在预设变更时更新对应区域并备份旧文件，不用运行后保存的区块内容判定版本。固定石碑从 Waystones 注册表恢复身份，重启、更新地图不重置激活。

## 第五馆：太晶化与模拟测试

- 第五馆在坂木的战后对白结束时完成主线。先接下一馆主线，再发「帕底亚的神秘力量」和「来测！」；教授的 MineChat 短信只是提示，不作为接取条件。「来测！」等到玩家进入岩石系模拟馆并离开 `cobblebash:gym_void` 后才推进，不要求胜利。
- 太晶教学在地面馆主题私人副本进行。玩家手持或佩戴太晶珠后才能开场，按绑定键成功太晶化后对方才派宝可梦，战胜两位对手后回坂木处领取奖励。副本每名训练家只有一个太晶位，换将不补充。太晶状态只存在于实时战斗会话和实体同步数据，不写入宝可梦存档；太晶碎块仍交由 Mega Showdown 处理。
- 新增场景角色在 `FixedStoryActors` 注册固定身份和实际站位。亚玛多、小三郎仅在其对白镜头中按玩家显示。战斗用宝可梦属于副本，不得加上 `rumble-scene-actor`。使用实体 tick 每 100 刻检查固定演员：离开站位的水平格或垂直偏移超过 5 格时，若站位区块已加载且没有碰撞就复位。玩家定时任务放玩家 tick；仅跨区块实体加载批次保留服务端 tick。
