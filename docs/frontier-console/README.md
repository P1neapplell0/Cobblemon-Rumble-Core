# 对战开拓区 · 操作台原型

打开 `index.html`，默认是公开房间网格，点可加入的房间卡片进配队，右上角创建房间。每张卡可预览双方的头像、赌注和已选阵容。也可用顶部标签查看配队和 PK。

- 点带光圈的空位选择宝可梦；至少选一只才能准备。点我方已选宝可梦的卡片主体可展开配招；右上角的 ⇄ 切换宝可梦，右下角的道具格更换或卸下携带物。两个选择层都可以搜索，携带物可过滤 Mega 进化石。
- 点击配队页的「帮助」可查看三种操作。演示用的直达链接：`?view=lineup&panel=species`、`?view=lineup&panel=mega`、`?view=lineup&panel=help`、`?view=lineup&empty=1`。
- 参考 ArcQuest 1.0.14 的 Ore 界面，用亮边、暗底和凹槽区分凸起按钮和输入框。此目录不进游戏资源；游戏落地时要用 Cobblemon 原生换招渲染，在终端同一页处理开拓区的配队草稿，不能将修改写进玩家自己的队伍。

商品示例来自 Cobblemon 和 Mega Showdown 的物品贴图；房主头像为 Minecraft 默认皮肤的裁切，宝可梦头图来自 PokéAPI 精灵图。房间、价格与阵容均为示例数据。
