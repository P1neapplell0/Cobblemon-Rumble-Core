# 主题竞技场

## 场地分配

| 对战来源 | 场地选择 |
|---|---|
| 试炼殿堂 | 岩石馆用采石场，草馆用温室，幽灵馆用幽影圆场，冰馆用冰晶场，地面馆用赤砂峡谷，火馆用熔炉，恶馆用午夜舞台，电馆用电力实验所。小弟和馆主共用对应主题。 |
| RCT 路人训练师 | 取发起挑战的群系。雪地和冰原用冰晶场，海洋、河流和海滩用水岸场，沙漠、恶地和热带草原用赤砂峡谷，丛林和沼泽用温室，森林和针叶林用林间场，山地用采石场。 |
| CobbleBash 模拟道馆 | 取道馆属性。四天王按其道馆的第一种可映射属性选场，冠军用空中场。 |
| Mega 模拟试炼 | 取 Mega 形态的主属性，其次取副属性。对应八馆属性优先使用八馆主题，其他可映射属性使用水岸场、超能场或空中场等共用主题。 |
| 玩家对战 | 取发起方创建副本时所在的群系，复用 RCT 路人战的群系映射。 |
| 其他情况 | 未匹配到主题或区块包不完整时使用原竞技场。 |

所有场地使用同一个平整战斗面和隔离边界。玩家从西边蓝色区出战，主题场地东边为红色部署区。`ArenaTheme` 管理群系和属性映射。整合包从 `modpack_override/config/custom_instances/region/rumble_arena_*/region/` 部署区块，服务启动时写入对应的私有副本定义。NPC 挑战通过原入口创建副本，回到发起位置后结算。

## 生成和结算

`python3 scripts/generate-themed-arenas.py modpack_override/config/custom_instances/region` 生成全部 12 套场地，也可在路径后面指定要重建的主题，需要安装 `nbtlib`。三张 image2.6 概念图和提示词存放在 [arena-concepts](arena-concepts/)，对应主题的建筑、材质和围栏由生成脚本落实为游戏区块。

RCT 胜利沿用本身的战利品、冷却和击败记录，额外发放 `min(1200, 100 + 5 × 敌方队员等级总和)` 宝可币。CobbleBash 继续处理进度、重复挑战和通关物品，普通训练师默认发 500 宝可币，馆主和联盟对手默认发 2,000，金额取自 CobbleBash 现有配置。外部训练师对战采用玩家手动派出一只宝可梦的实时战斗规则。战败和中途退出只处理各入口的恢复逻辑。
