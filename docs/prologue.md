# 序章：初鸣的火花

流程由 ArcQuest 保存，任务 ID 为 `cobblemon_rumble_core:first_spark`：**广场上的博士 → 最初的伙伴 → 前往模拟训练场 → 对战第一课 → 皮卡丘的试炼 → 大师之路的第一步**。第一次进服落在主城，和博士确认名字后才开放 Cobblemon 原版初始伙伴面板。选完伙伴后博士发起简报，接受邀请进入个人副本；退出或掉线后可以回博士处重试，已经完成动作课的玩家可直接重试实战。追踪序章时，ArcQuest 会在入场前和返城后标记主城里博士的位置；进入训练后移除路标。

## 地图和部署

- 主城为 `cobblemon_rumble_core:gyms`，使用从旧道馆地图迁移的 16 个区域文件，不迁入旧实体存档。开服时以预设区域文件的 SHA-256 对照存档里的 `.rumble-map-sha256.properties`，只安装缺失区域或预设已变化的区域。第一次启用校验会同步旧测试存档的地图；覆盖前的区域文件存入主城目录下的 `.rumble-map-backups/`。实体、玩家和 Waystones 数据不随地图覆盖，固定石碑会按坐标接回原 UUID。地图和裁剪模板保留 WorldBlocks Team 的原授权说明。
- 广场设施：治疗仪 `(-19, 50, 0)`，电脑 `(-9, 50, 0)`；两个训练模拟机分别在 `(-14, 50, 5)` 和 `(-14, 50, -5)`，均打开同一个训练菜单。
- 原传送锚点 `(-14, 50, 0)`，新玩家落点 `(-16, 50, 0)`，大菠博士 `(-14, 50, -2)`。这些是方块坐标，实体放在方块水平中心。首到标记由内嵌的 Simple Player Data Manager 保存；不依赖旧核心。
- 客户端和服务端均安装 ArcQuest `1.0.14`、Custom Instances `1.0.0`（使用支持自定义结算、状态 HUD 和不限人数房间的本地重编版）及[依赖清单](development-dependencies.tsv)中的对应版本。若装 JEI，使用 `19.51.0.418`。Simple Player Data Manager 已内嵌在成品中。徽章演出使用 Cinematics `1.4.0`，随整合包提供的配置仅保留徽章动画。
- 发布整合包时，将 `modpack_override/config/` 下的内容按原目录结构复制到整合包的 `config/`。主城模板在 `config/cobblemon_rumble_core/maps/gyms/region/`，教学场和正式竞技场模板在 `config/custom_instances/region/`。JAR 只补装缺失的副本定义，不内置区块。本地更新预设后运行 `./gradlew syncRunOverrides`，同步到 `run/`、`runs/neoforge-client/` 和 `runs/neoforge-server/`，不直接改动存档。
- 全局禁用原版生物自然刷新，保留村民等旧核心例外。主城、教学和正式竞技场副本额外禁用 Cobblemon 野生宝可梦和随机 NPC。主城博士及馆内训练家由 `FixedStoryActors` 首次放置并持久化；训练用皮卡丘和副本出战角色由各自副本流程生成。
- 主城保留 42 个 Lootr 奖励箱，恢复旧核心的 7 张 `my_loot` 奖励表。其余 41 种缺失装饰使用现有方块补齐，逐项映射见[地图方块替换表](hall-block-replacements.md)。曾以缺失依赖启动并保存的测试世界需用新世界验证新版模板。
- 石碑菜单和手机的「主世界」按钮共用村庄落点。以主世界出生位置为搜索起点，优先定位 Cobblemon Additions 的百货超市村庄 `bca:village/default_large`，在中心建筑外侧找安全地面，并把落点保存在世界中。未加载该结构或未找到时先尝试原版村庄，再回退到世界出生点。正式服需要由兼容的 Additions 安装方式将该结构注册进主世界。
- 序章、小队集结和道馆任务使用旧核心样式的紫色新任务通知，可在 ArcQuest 对话上方显示。`modpack_override/config/arc_quest-toasts.toml` 关闭 ArcQuest 默认接取通知，避免重复显示。

## 模拟训练场

模板位于 `modpack_override/config/custom_instances/region/prologue_plaza/region/`，与主城独立存储。以 `(-14, 0)` 为平面中心，裁进 `|dx| ≤ 42`、`|dz| ≤ 46`、`|dx| + |dz| ≤ 65` 的八边形，只留中央广场，移除通往八馆的外围道路；边缘在 `y=43–91` 补上屏障。模板清除了旧方块实体与待处理的方块 tick，并在 `y=49` 用平滑石台阶填平桦木与石英边框之间的 888 格环形凹槽，与两侧边框齐平。竞技场入口 `(-18, 50, 0)`，皮卡丘初始位置 `(-11.5, 50, 0.5)`。

裁图复现（Python 需要 `nbtlib`；输出到空目录再比对）：

```sh
python3 scripts/crop-prologue-arena.py \
  ../CobblemonEbonyPhantomCore/src/main/resources/civ_dim_preset/gyms_dim/region \
  /tmp/rumble-prologue-arena
```

练习顺序是 **发起挑战 → 退出实时对战 → 重新进入实时对战 → 移动与跳跃 → 锁定目标 → 普攻 → 重击 → 格挡电球 → 完美格挡 → 释放招式 → 实战**。退出与重进使用 RTC 原生切换按键，各自确认服务端会话已切换后通过，退出时保留已派出的伙伴。教学允许走动、跳跃和调整站位；移动累计至少 3.5 格且完成一次起跳落地才通过。锁定读取 RTC 的原生锁定目标。两节格挡课都以皮卡丘的电球实际命中为准。完美格挡必须命中 RTC 的原生时机窗口；提前举盾只算普通格挡，会提示松开并重试。没挡住或躲过也会重新发射。

关键动作出现时，只让正在教学的 `ServerLevel` 短暂停顿；格挡只在电球飞行时降至半速。HUD 显示实时改绑按键，操作通过有提示音和确认文字，大菠博士只在关键节点于字幕左侧淡入。练习用皮卡丘为 15 级，实战前受保护。击倒后播放博士返程提示并回城，无默认通关标题和 DPS 面板；任务完成和副本战斗记录仍保存。

## 试炼殿堂与小队集结

- 选定初始伙伴时解锁「打开宝可梦详情与物品栏」「更换宝可梦招式」「让宝可梦进化」三篇指南；完成皮卡丘实战后解锁「实时战斗」。操作提示使用当前按键绑定。
- 训练返城后，序章最后一阶段「大师之路的第一步」重新标记大菠博士。完成关于八座道馆和晕眩捕捉的对话后，获得宝可梦图鉴与 10 个精灵球，开启主世界通行并接取支线「小队集结！」。接取任务时显示紫色 ArcQuest 弹窗。
- 「试炼殿堂」传送石碑位于中心锚点 `(-14, 50, 0)`。右键石碑，或从手机默认开放的传送石碑 App 打开原生列表，底部可切换「主世界／试炼殿堂」。对话完成前剧情目的地锁定。回城默认落在石碑西侧两格，去主世界默认落在公共出生点附近。
- 「小队集结！」依次要求用石碑菜单前往主世界、在实时对战击倒野生宝可梦后趁晕眩投球、成功收服，以及让当前队伍同时拥有六只。新伙伴按 Cobblemon 原规则进入队伍或电脑。完成时一次性发放 2,000 宝可梦币与钻石剑、斧、铲、锄各一件。

## 馆主副本与成长

- 馆主对话打开 Custom Instances 原生大厅。挑战资格按玩家检查，建房后在大厅组队；进场后，每人须在蓝区派出伙伴并进入实时模式，全员就绪才开战。`rumble_gym_*` 不设房间人数上限，馆主每只宝可梦的生命上限按开战人数乘算，退队不重算；单个实体仍受 Minecraft 的生命属性上限约束。重战走独立对话，不重复发首通奖励。
- 首通分别按每位玩家的任务进度结算，发徽章和宝可梦币；小弟挑战也有一次性金币奖励。首馆胜利后追踪博士回访，领徽章盒后解锁个人交易；之后只有博士默认对话常驻交易入口。
- 序章结束自动接取等级、图鉴和徽章三组成长任务，达标自动发奖。稀有奖励使用 Prism Ball `1.0.4` 与 Horizon Cobblemon Items；对应奖励物品未注册时保留里程碑进度。虚拟道馆暂不开放。
- 岩石徽章的结算对话结束后，MineChat 弹出到货短信，同时接取博士回访任务；不读不回也能推进。回访解锁[博士商店](professor-shop.md)，退出回访对话后发放草系道馆主线和蓝色支线「大菠博士的补货委托」。
- 补货委托只收普通、黑色或天空玉石中的一块。火箭队演出只发给对话玩家；与武藏、小次郎的双敌战复用私人竞技场。退出或战败时保留已交玉石阶段，战胜奖励 2,000 宝可币，收下古代大师球及六种力量道具后解锁努力值指南。
- 旧包里的玉石晶簇可见于附加模组的结构模板，未找到旧核心单独的洞穴分布配置。这里使用核心中的 `cave_tumblestones` 世界生成规则，给新主世界区块的洞穴岩面添加三种可采晶簇。
- 战斗曲在确认开战后淡入，替换宝可梦期间不断，离战后淡出。竞技场候场不播放。

## 联机验收清单

1. 用新世界、新玩家进入；核对落点、博士朝向、ArcQuest 序章及初始伙伴入口锁定。追踪序章时确认博士路标显示正确；取消追踪或进入训练后确认路标消失。靠近博士看身侧交互提示（独立键帽与操作），离开或被墙挡住时隐藏，改绑「与 NPC 对话」并验证新键可用、离开后背包键照常。
2. 确认对话选项是「我叫<玩家名>」，博士会转向交谈者；客户端启用 Quark 表情后，核对欢迎挥手、问名思考和入场指引手势。选完伙伴后无需再按对话键。开启转场，验证只有本人能进入副本、道路出口被封住。
3. 把挑战、实时对战切换、锁定、攻击、使用与热栏按键改绑。确认用改绑键实际退出、在伙伴仍在场时重新进入，随后能自由移动、必须起跳落地、错误输入不推进；检查中央环形地面平整。未被电球命中或未格挡都不算通过；完美格挡课先尝试提前举盾，确认只触发普通格挡并重试，再在命中前举盾通过。另一个玩家在其它维度同时活动时不受副本降速影响。
4. 实战击倒（包括实时战斗的「影子分身」伤害）、无默认结算标题或战报、回城后重登，确认任务保持完成。另用新玩家中途执行 `/custominstances leave` 退出、重试，以及完成动作课后退出再重试。
5. 选定伙伴和完成训练时分别检查指南解锁；博士后续对话结束后查新任务弹窗、支线分组和石碑路标。用实体石碑去主世界、手机 App 回城。收服后核对电脑；五只在队时任务不完成，六只才发全额奖励。
6. 首馆开门后依次完成小弟单打、两名 NPC 联手战和馆主战。检查两名 NPC 的派出与收回互不影响，玩家倒下后能从替补页选将，馆主胜负动画后返回道馆。核对徽章与下一馆路标。
7. 两名达到首馆挑战阶段的玩家从同一大厅组队。确认一人准备出战时不开始、两人都进入实时模式后馆主队伍为双倍血量；返程后各自只收到一次首通奖励。由一人领徽章盒并买一枚精灵球，确认只扣该玩家 200 宝可梦币、另一人仍未解锁交易，随后重开馆主大厅。

## 实时战斗：影子分身

影子分身最多同时存在两只，存活约 8 秒（160 个游戏 tick）。上一批还有分身存活时重放不会补数量或续时。分身保留吸引仇恨的能力；每只提供 15% 的代挡概率（合计最高 30%，代挡后消失），单只攻击威力参数最高为 3，出手间隔至少 50 tick。仍尊重 RTC 已配置的更低分身数量、威力及更长攻击间隔。闪避等技能的纯视觉残影不受影响。

### Cobblemon Additions 世界生成

沿用旧核心的村庄间距、结构权重和五个生物群系标签，不包含结构模板。识别到 `cobblemon-additions` 模组时自动加载内置覆盖；独立数据包安装方式使用 `modpack_override/optional_datapacks/bca_distribution.zip`，优先级高于 Additions。
