# 实时战斗：野外场景交互

| 招式或命中 | 场景反应 |
| --- | --- |
| 近战招式 | 挥击后第 4 刻，按挥击方向检查近距离第一个方块，可打掉树叶、草、蕨和蜘蛛网，不掉落。 |
| 冲击波 | 第一圈沿面朝方向、略向下检查最多 5 格，同样只破坏这些软方块。 |
| 火系 | 接触可燃表面时可点燃紧邻的空位；普通冰融为水（超热维度直接消失）。实际伤到普通实体时可点燃 3 秒，不给宝可梦或其受控玩家代理附加原版着火。 |
| 冰系 | 将上方为空气的露天水源变为霜冰，40 刻后进入原版霜冰融化检查；不冻结流水。 |
| 水系 | 熄灭接触到的火焰方块，清除受击普通实体的原版着火；不更改宝可梦对战状态。 |

元素方块判定接入近战、冲击波、光束、持续喷射和投射物撞墙；不从粒子反推命中。每次近战首段、冲击波首圈、光束/喷射首脉冲或单枚弹体只检查第一个接触方块。只响应玩家操控的宝可梦；试炼殿堂和所有副本禁用。检查世界边界、区块加载、玩家交互权限及 NeoForge 破坏/放置事件，跳过方块实体和不可破坏方块。原版火焰后续传播仍受世界规则影响。
